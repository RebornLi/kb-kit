# P5 交付报告：审计与"确认后修复"

## 一、最重要的成果：自指问题检索止血

P4 暴露的盲区（"正典是什么"这类**问系统自身**的问题检索不到），P5 治好了。

### 三步定位（每步都有对照实验）

| 手段 | 效果 |
|---|---|
| 双向同义词扩展（修 `_expand_query`） | 机制修好了，但对这类问题**增益有限** |
| 标题/路径加权（`_title_boost`） | 机制生效，但只命中「正典」一个词（覆盖 0.125，仅 ×1.07） |
| **概念索引 `docs/concepts.md`** | ✅ **一击命中** |

**消融实验证明主因是概念索引**（不是加权机制）：

```
移除 concepts.md 后：
  「知识结晶 正典 是什么」 → 20-技术 Technology/测试 Testing/测试-p5.md   ← 完全无关
  「置信分怎么算」        → docs/p3-report.md（第二相关，不是定义）
恢复 concepts.md 后：
  两题都 → docs/concepts.md（第一）
```

对 6 个自指问题的实测：**全部命中第一**（分数 2.4–2.9，第二名 1.6–1.9）。

### 为什么"集中定义"有效

这些概念散落在各份 P0–P4 报告里，单篇关键词密度低（"正典"在千词文档里只出现 3 次），
被大量"讲 kb-kit 但不讲该概念"的长文挤下去。集中定义 = 提高关键词密度 + 标题聚焦。

**顺带修的真 bug**：`_expand_query` 只做「同义→规范」，查"正典"时规范词还是"正典"，
展开后**完全没有新增词**——74 条同义词表等于白建。现在做**双向**扩展。

## 二、`kb audit`：结构审计 + 确认后修复

补齐 `kb healthcheck` **没有**的三类检查（对照 wiki-lint）：

| 检查 | 说明 | 当前实测 |
|---|---|---|
| **溯源漂移** | 正典里"推断"断言占比（hub 页漂移危害最大） | 0 篇 |
| **标签簇内聚** | 共享标签的页之间互链率 <0.15 报警 | 54 个簇偏低 |
| **索引一致性** | `_MOC`/`_INDEX` 清单与实际文件对账 | 5 处 |
| 孤儿页 / 死链 / 陈旧 / 缺 summary | 复用已有能力，统一出口 | 51 / 51 / 0 / 0 |

**安全协议**（照搬 wiki-lint）：

```
kb audit scan            # 只读，写审计快照 + 人读报告
kb audit fix             # dry-run：打印逐项清单（74 条动作）
kb audit fix --confirm   # 才落盘；**合并/删除页面不在自动修复范围**
kb audit log             # 审计历史 + 修复日志
```

## 三、过程中修掉审计自身的 3 个误报根因（这是本轮的技术含量所在）

审计工具第一版给出的数字**全是错的**，逐个定位：

### 1. 把"证据层"当不存在 → 误报 112 条死链
`_MOC` 与正典大量链接指向 `raw/_curated/<原路径>`（保号原文）——**那是存在的文件**，
但我的采样排除了 `raw/`。修：用**全库存在集**（含 raw）判定死链。

### 2. 把星标当链接 → 误报死链
MOC 用 `- [[X]] —— 摘要` 格式，我的正则把 `X]] —— 摘要...` 整段当成链接目标。
修：正则只取 `[[...]]` 内部。

### 3. **把生成产物排除出入链统计 → 误报 683 篇孤儿页**（最严重）
`_MOC.md`（1834 条链接）、`_INDEX.md` 被 `is_generated_report()` 排除在采样外，
于是它们的链接**完全不算入链** → 683 篇正常笔记全成"孤儿"。
修后孤儿页 **683 → 51**（真实值）。

> 教训与 P2/P4 一脉相承：**"没接线"和"没数据"长得一样**。
> 一个指标异常到荒谬（683/1129 篇全是孤儿）时，先怀疑工具，再怀疑库。

### 4. 治本而非打补丁
`kb link moc` 生成器**不过滤已消失的笔记**（索引里残留被合并/改名的条目）→ 每轮都再造死链。
已在生成器里加"只写当前真实存在的笔记"过滤，MOC 自身保持零死链。

## 五、已知局限（诚实标注）

1. **子目录 `_INDEX.md`（15 条悬空）** 由其它流程生成，本仓库没有它的生成器 → 只能人工处理
2. **标签簇内聚 54 簇偏低**：该指标未考虑 `related_to` 字段与 RSI 补链区块里的链接，
   数值偏悲观，需再校准（当前不宜作为"必须修"的依据）
3. **MOC 死链 51 条**：目标是"已被结晶合并的旧碎片名"；`fix` 能改写的会改（74 条动作），
   改不了的转纯文本注释——**判断哪条该指向哪个正典需要人**，不给自动化
