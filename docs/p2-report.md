# P2 交付报告：检索与分块（上下文强化 + 父子块 + RRF）

> 黄金集从 12 题扩到 **30 题**（事实查找 / 操作复现 / 决策依据 / 多跳关联四类）。
> 所有数字来自同一次评测。

## 一、最终指标（30 题 · Top-10）

| 档位 | canon@K | top1 正典 | top3 全正典 | 片段长度 | 单查询延迟 |
|---|---|---|---|---|---|
| **现在（默认）** | **91.0%** | **97%** | 67% | 94 字 | **0.50s** |
| 关闭分层（等价 P0 前） | 75.3% | 50% | 43% | 109 字 | 0.55s |
| 开启语义重排（对照） | 91.0% | 97% | 67% | 94 字 | 0.84s |

**分层降级贡献最大**：top1 正典率 **50% → 97%**，正典占比 **75.3% → 91.0%**。

## 二、四项交付与实测结论

### 1. 上下文强化索引（CCH）✅ 保留

- `pipeline/contextual.py`：确定性 CCH（标题/路径/域/标签 + 首句）**零成本**；短块可选 LLM 上下文
- 上下文**只进索引文本与 meta，不写 .md 正文**（正文保真、零副作用）
- 索引 v4：`meta.context` 覆盖 1475/1475
- 依据：Anthropic Contextual Retrieval（嵌入+BM25 降失败率 49%）

**诚实说明**：**没有单独量化 CCH 的增益**（需建两份索引对比）。依据是公开实测（10–20%），
本项目内未单独测量——不能算作已验证收益。

### 2. 父子块（查子块 → 返回父块）✅ 保留

- 索引记录 `parent`（直接父）与 `root`（顶层），沿 `chunk_of` 链回溯 + **文件名兜底逐层向上**
- 命中碎片时回填 `parent` + `parent_excerpt`（900 字窗口）；直接父覆盖 646 篇

**过程中发现并修掉的三个真问题**：
1. `_parent_block` 算出的 `extra` **根本没并进返回值** → JSON 里 parent 恒为 None
2. 文件名兜底贪婪剥后缀（`-p2-p2` 一刀切到主文档）→ 改成**逐层向上**
3. **父页可能只是目录页** → 回填内容变成一串指针；现在检测到就改用「同父下得分最高的兄弟碎片」，
   并把 `is_index_stub` 扩展到「`chunk_of` 存在但正文 <200 字」的中间层目录页

### 3. RRF 融合 ✅ 保留

线性加权换成 **Reciprocal Rank Fusion**（`Σ 1/(60+rank)`）：对两路打分量纲免疫。
实测 canon@K **89.0% → 91.0%**。

### 4. 本地嵌入语义重排 ⚠️ 做了，但**默认关**

- `pipeline/embed_rerank.py`：`:8081` qwen3-embedding（4096 维）算 (查询,文本) 余弦，与 RRF 分融合
- 只算 top-25，6s 预算，磁盘向量缓存（已缓存 261 条）
- 实测：**top1/top3 与不重排完全一致**，只是换了 top3 内部顺序；成本 +0.3s/查询
- **处置**：默认关（`KB_EMBED_RERANK=1` 开启）。基准没测出增益就不该加默认延迟

## 三、顺带修掉一个"静默降级"根因

`kb_embed`/`curate` 只读环境变量，而 **cron/systemd/自动化读不到 `~/.bashrc`** → key 缺失 → 静默降级。
新增库内模型配置 `.kb/model.json`（600 权限、已 gitignore），优先级 **环境变量 > 文件**。
现在无环境变量也能用。

## 五、另一个由 P2 引出的真问题（RSI 嵌入"自动启用"事故）

加了库内模型配置 `.kb/model.json` 后，`kb_embed` 的可用性从 False 变 True。
而 `kb_rsi._use_embed()` 的旧逻辑是「**自动探测可用即启用**」→
`kb_l4` 的接地检查（`kb_rsi.collect()` 遍历全库）开始为**每篇笔记**调嵌入：

```
kb_l4 docket：~10s  →  >300s（超时，0 字节输出）
连带：验收探针 P3「L4 含 lc rung」失败
```

顺带还炸出一个潜伏 bug：`kb_rsi.cos()` 在 dict（字面向量）与 list（嵌入向量）混用时
`b.get()` 直接 AttributeError——**嵌入路径首次真正启用就会崩**。

**处置**：
1. `_use_embed()` 改为**显式 opt-in**（只有 `USE_EMBEDDING=1` 才走语义向量）。
   理由：语义向量是研究层增强，不能因"配置文件出现"就自动启用。
2. `cos()` 对混合类型返回 0（保守，不伪造相似度），不再崩。

修后 `kb_l4 docket` 回到 **12s**，探针恢复 **16/16 PASS**。
