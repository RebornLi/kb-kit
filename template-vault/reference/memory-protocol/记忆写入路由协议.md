# 记忆写入路由与审计协议

## 目标文件职责边界
| 文件 | 唯一职责 | 允许的内容 | 禁止的内容 |
|------|---------|-----------|-----------|
| SOUL.md | 认知宪法 | 认知框架、推理模式、不可变核心、平衡原则 | 工具路径、平台格式、具体操作流程 |
| AGENTS.md | 操作手册 | 会话流程、安全边界、质量门禁、执行规则 | 认知哲学、深度分析框架 |
| TOOLS.md | 工具参考 | 工具名称、路径、配置、健康检查命令 | 行为规则、认知原则、用户偏好 |
| USER.md | 用户档案 | 用户信息、通信偏好、学习到的偏好 | 通用行为规则、系统配置 |
| MEMORY.md | 长期记忆 | 经验教训、决策背景、待提炼的经验 | 可作为全局规则的硬约束 |

## 写入方式决策
| 语义重叠度 | 操作 | 方法 |
|-----------|------|------|
| > 60% | 替换 | 新表述替换旧段落 |
| 30-60% | 合并 | 在现有段落末尾追加新条款 |
| < 30% | 新建 | 新建独立段落 |

## 写入后审计
写入完成后检查：
1. 新增内容是否与职责边界一致
2. 是否引入与现有规则矛盾的条款
3. 文件总字符数是否在预算内
4. 信号密度（行为指令 / 总字符）是否 ≥ 15%
