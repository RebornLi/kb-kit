# 🚀 如何开始你的知识库

这是你刚用**一键套件**建好的知识库。5 步上手：

## 1. 先读首页
打开 `🏠-知识库首页`，总览结构与规则。

## 2. 写第一条知识
在 `00-收件箱 Inbox` 新建一条（或改现有示例）。记得带 `frontmatter`。

## 3. 建索引
```bash
kb rag index
```

## 4. 试检索
```bash
kb query "怎么备份知识库"
```

## 5. 跑一次成长引擎（看它怎么自动维护）
```bash
kb ingest         # 收件箱 triage 清单
kb feedback ingest # 命中信号
kb link suggestions # 孤岛补链建议
kb healthcheck    # 健康巡检
```

## 常用命令速查

| 命令 | 作用 |
|------|------|
| `kb rag index/query` | 建/查本地向量索引 |
| `kb ingest` | 收件箱摄入 triage |
| `kb feedback ingest/apply` | 命中信号 |
| `kb link suggestions/apply` | 孤岛补链 |
| `kb recall deck/mark` | 间隔回忆 |
| `kb healthcheck` | 健康巡检 |
| `kb dashboard` | 生成治理面 |
| `kb backup` | 全量备份 |
