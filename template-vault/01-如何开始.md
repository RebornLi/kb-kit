# 🚀 如何开始你的知识库

这是你刚用**一键套件**建好的知识库。5 步上手：

## 1. 先读首页
打开 `🏠-知识库首页`，总览结构与规则。

## 2. 写第一条知识
在 `00-收件箱 Inbox` 新建一条（或改现有示例），记得带 `frontmatter`。

## 3. 建索引
```bash
kb rag index
```

## 4. 试检索
```bash
kb query "怎么备份知识库"
```

## 5. 跑一次成长引擎（看它怎么自动维护）
```bash
kb ingest          # 收件箱 triage 清单（只读）
kb feedback        # 命中信号统计
kb link            # 孤岛补链建议
kb healthcheck     # 健康巡检（all）
kb dashboard       # 生成治理仪表盘
```

## 常用命令速查

| 命令 | 作用 |
|------|------|
| `kb rag index` / `kb query "…"` | 建/查本地向量索引 |
| `kb ingest` / `kb ingest move` | 收件箱 triage / 路由（move 为写操作） |
| `kb feedback [ingest\|apply]` | 命中信号（apply 写回 importance） |
| `kb link [suggestions\|apply\|moc]` | 孤岛补链 / 知识地图 |
| `kb recall [deck\|mark --grade …\|status]` | 间隔回忆（SM-2） |
| `kb healthcheck [all\|deadlinks\|…\|freshness]` | 健康巡检 |
| `kb validate [--strict]` | frontmatter 校验 |
| `kb dashboard` | 生成治理面 |
| `kb clean [dry-run\|apply\|chunk\|refine\|taxonomy]` | 清洗/分块/一键整理/标签归一 |
| `kb backup [daily\|weekly]` | 全量备份 |

> 需要操作其它库：`--root <路径>` 或 `KB_ROOT`（优先级 `--root` > `KB_ROOT` > 脚本目录）。
