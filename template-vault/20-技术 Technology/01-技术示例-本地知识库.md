# 技术示例：本地知识库 RAG 原理

> 示例笔记。展示 `技术经验模板` 的写法，以及 `_vec` 向量检索如何工作。

## 📝 概述

本地语义检索：扫描笔记 → 构建 TF-IDF/BM25 向量索引 → 提问时求余弦相似度取 Top-k。

## 🛠️ 操作方法

```bash
# 在建好的 vault 里（已装 kb 启动器）
kb rag index      # 重建向量索引 → vector index/
kb rag query "怎么备份" --top 3
```

## 🐛 踩坑记录

### 问题描述
中文分词缺 jieba 时检索质量差。

### 根因
本项目**故意不依赖 jieba**：用 unigram+bigram 兜底，免安装、跨平台。

### 解决方案
中文字符拆单字+双字组合，拉丁词照常用正则。够用且零依赖。
