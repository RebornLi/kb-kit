# 决策示例：本地检索方案选 TF-IDF

> 结论先行：我们决定用 **本地 TF-IDF/BM25**，因为 **零依赖、跨平台、可离线**，放弃 **云端嵌入模型**。

## 📋 决策背景

- 需要一个人人能一键部署、不用买 GPU/API 的本地检索。

## 🔀 备选方案

| 方案 | 优点 | 缺点 | 成本 |
|------|------|------|------|
| TF-IDF/BM25 | 零依赖、离线、可移植 | 语义弱于嵌入 | 免费 |
| 本地嵌入模型 | 语义强 | 要下模型、慢、装依赖 | 高 |
| 云端 API | 语义最好 | 花钱、要联网、隐私 | 按量 |

## ✅ 最终决策

- **选择**：TF-IDF/BM25
- **原因**：一键部署优先，跑在任意机器都能用
- **放弃**：云端 API（隐私+成本）、本地模型（环境重）
