# 04-质量与指标

知识库的「度量层」：把巡检与校验的**数值化结果**沉淀下来，作为健康门禁与成长追踪的依据。
与 `01-SOP-新增入库`、`02-SOP-流转归档`、`03-SOP-健康巡检`、`命名约定与标签词库` 共同构成治理闭环。

## 一、质量指标（可计算）

| 指标 | 含义 | 命令 | 健康阈值 |
|------|------|------|----------|
| 死链率 | `[[...]]` 断链占比 | `kb healthcheck deadlinks` | < 2% |
| 标签越界 | 不在白名单的自由 tag | `kb healthcheck tags` | 0 |
| 空目录数 | 无内容的分区子目录 | `kb healthcheck empty` | 0 |
| 骨架笔记 | 过小/过短的笔记 | `kb healthcheck skeletons` | 0 |
| frontmatter 缺失 | 缺 tags/status/domain/importance | `kb healthcheck frontmatter` | 0 |
| 顶层纪律 | 顶层非 `NN-` 编号目录数 | `kb healthcheck discipline` | 0 |
| 超长未分块 | 正文超过颗粒度上限 | `kb healthcheck overlong` | 0 |
| 孤儿笔记 | 无入/出链 | `kb healthcheck orphans` | 0 |
| 校验硬错误 | frontmatter 必填缺失/取值非法 | `kb validate --strict` | 0 |
| 陈旧/不可检索 | review_after 到期 或 非 active/stable | `kb healthcheck freshness` | 0 |
| 近重复 | 相似度≥0.7 的笔记对 | `kb clean report`（写 `clean_suggestions.md`） | 0 |
| 复习负债 | 到期未复习篇数 | `kb recall status` | 少 |

## 二、质量门禁

- `kb validate --strict`：存在硬错误即退出码 1，可作为入库 / 定时任务的前置门禁。
- 各巡检子命令发现项 > 0 时退出码 1（供 cron / 监控察觉，不 abort 流程）。
- `kb dashboard` 汇总告警块到 `70-知识治理 Governance/_INDEX.md`，首页可见。

## 三、提升路径

1. 缺字段 → 按 `01-SOP-新增入库` 补齐；不达标项进待审队列。
2. 超长笔记 → `kb clean chunk` 按 `##` 标题分块。
3. 死链 / 孤岛 → `kb link` 采纳建议补链（优先跨域弱连接 = 洞察来源）。
4. 标签越界 → 归入白名单或改用规范 tag（见 `命名约定与标签词库`）。
