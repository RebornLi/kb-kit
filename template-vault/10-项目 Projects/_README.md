# 10-项目 Projects

> 进行中 / 有明确目标与时间线的**项目**放这里（面试准备、职业转型、某个交付物……）。
> 项目收尾后下沉到对应成果区或归档，避免"项目区变成坟场"。

## 模板

新建项目笔记用 `50-模板 Templates/项目笔记模板.md`。

## 本区示例

- [[00-项目示例-职业转型|项目示例：职业转型]]

## 维护约定

- 单项目单文件（大则分块 `-p1`、`-p2`）。
- `frontmatter.phase` 标记所处阶段（需求/设计/开发/测试/上线/运维）。
- 关键决策在 `30-决策日志` 留痕，这里放链接。
