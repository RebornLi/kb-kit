# 🧹 知识清洗管道规范

> 规则来源：[[📖-知识库管理方案.md|📖-知识库管理方案]] §5。成长引擎按此节拍自动维护知识库。

## 每日节拍（可选 cron）

1. **ingest**（`intake_triage.py review`）→ `intake_triage.md`：收件箱四维打分。
2. **apply move**（`intake_triage.py apply --move`）→ 按 `kb_target` 路由到 PARA 区。
3. **feedback ingest**（`feedback_loop.py ingest`）→ `feedback_hits.md`：记录命中信号。
4. **补链**（`link_engine.py apply`）→ 孤岛笔记补双向链接。
5. **recall deck**（`recall_schedule.py deck`）→ `recall_deck.md`：今日该回忆的笔记。
6. **dashboard**（`dashboard.py`）→ `70-知识治理 Governance/_INDEX.md`：健康面。

## 人工动作（审后再跑）

- `feedback_loop.py apply`（提升 importance，只升不降）
- `recall_schedule.py mark`（标记已回忆）
- `memory_sync.py promote`（晋升高质量记忆）

## 铁律

- 任何 `apply` 写前**先 checkpoint**（`--dry-run` / `review` 看清单）。
- `importance` **只升不降**，防刷票。
